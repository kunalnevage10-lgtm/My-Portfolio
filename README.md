A clean, modern, and lightweight personal developer portfolio website designed and developed by **Kunal Nevage**. Built using semantic **HTML5** and responsive **CSS3**, this site showcases professional projects, technical skillsets, and direct contact channels for recruiters, collaborators, and clients.

---

## 🎯 Objective

In software engineering, a personal web portfolio serves as a live, interactive resume.

The goals of this portfolio are:
- **Clean Presentation**: Eliminate bloated heavy JavaScript runtimes in favor of blazing-fast, accessible vanilla HTML/CSS.
- **Project Showcase**: Highlight key flagship engineering initiatives across Machine Learning, IoT Edge AI, and Full-Stack development.
- **Seamless Responsiveness**: Deliver an effortless viewing experience across mobile smartphones, tablets, and desktop monitors.

---

## ✨ Key Features

- **⚡ Blazing Fast & Zero Dependencies**:
  - Pure Vanilla HTML5 and CSS3—loads instantaneously with zero client-side framework overhead.
- **🎨 Modern Slate & Cyan Aesthetic**:
  - Styled with Deep Slate (`#2c3e50`) and Vibrant Azure Blue (`#3498db`) accents.
  - Interactive project cards with smooth subtle hover scaling (`transform: scale(1.02)`).
- **🏷️ Interactive Tech Stack Pills**:
  - Categorized skill tags (Python, Java, C++, DBMS, Web Development) with soft contrast badges.
- **📱 Responsive Layout**:
  - Fluid container architecture optimized for all viewport breakpoints.
- **📬 One-Click Contact CTAs**:
  - Direct mailto links, LinkedIn profile connectivity, and GitHub repository shortcuts.

## ⚙️ How to Run Locally

No build tools or package managers required!

### 1. Clone the Repository
```bash
git clone https://github.com/kunalnevage10-lgtm/My-Portfolio.git
cd My-Portfolio
```

### 2. View in Browser
Simply open `index.html` in your favorite web browser:
* **Windows (PowerShell)**:
  ```powershell
  Start-Process index.html
  ```
* **macOS**:
  ```bash
  open index.html
  ```
* **Linux**:
  ```bash
  xdg-open index.html
  ```

Alternatively, use the VS Code extension **Live Server** or run Python's built-in local server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## 🚀 Deployment (GitHub Pages)

To host this portfolio live for free via GitHub Pages:
1. Push this repository to your GitHub account (`https://github.com/<YOUR_USERNAME>/My-Portfolio`).
2. Go to repository **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://<YOUR_USERNAME>.github.io/My-Portfolio/`.
